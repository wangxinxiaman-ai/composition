# 解决 HTML 导出雷达图缺失及布局优化问题

## 1. 解决 HTML 导出雷达图缺失
*   **原因**：雷达图是使用 ECharts 动态渲染的 Canvas。当直接导出 HTML (`document.documentElement.outerHTML`) 时，Canvas 的内容（绘制的图形）不会自动包含在 HTML 源码中（Canvas 标签在源码里是空的）。
*   **解决方案**：
    *   在执行“下载 HTML”前，将 ECharts Canvas 转换为 **Base64 图片** (`chart.getDataURL()`)。
    *   将该图片插入到 DOM 中，隐藏原始 Canvas。
    *   这样导出的 HTML 文件将包含静态的雷达图图片，用户打开离线 HTML 也能看到图表。

## 2. 优化布局以减少空白和换页（紧凑化）
*   **合并卡片**：将“评分概况”（雷达图）和“维度得分详情”合并到一个卡片中，减少标题栏和边框占用的垂直空间。
*   **调整高度**：将雷达图高度减小至 `300px`，减少留白。
*   **打印优化**：在 `@media print` 中进一步减少内边距和间距，确保内容紧凑，避免不必要的换页。

## 执行步骤
1.  **修改 `downloadHTML` 函数**：添加将 ECharts 转换为 Image 的逻辑。
2.  **修改 HTML 结构**：合并右侧的评分卡片。
3.  **修改 CSS**：调整雷达图高度和打印样式。
