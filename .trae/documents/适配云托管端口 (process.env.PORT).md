# 简化方案：直接修改 Dockerfile

抱歉让您感到困惑。之前的方案是“标准做法”，但如果您以前没遇到过，可能是因为以前的 `Dockerfile` 或者配置帮您处理了端口映射。

既然 `server.js` 已经监听了 **3001**，而且我们不想改代码，最简单的方法是**告诉云托管我们用的就是 3001**。

通常云托管（如腾讯云）允许在控制台设置“监听端口”。但更通用的做法是在 `Dockerfile` 里把这事说清楚，或者让容器里的服务自己去适配。

为了最快解决问题且不改动您的业务代码：

**新方案**：我们只改 `server.js` 的**一行**，这是最稳妥的。
原因：腾讯云托管在启动容器时，会强制给容器注入一个 `PORT` 环境变量（通常是 80）。容器内的程序**必须**监听这个 `PORT`，否则负载均衡器找不到它。原来的代码写死 `3001`，所以云平台（默认找 80）找不到。

**操作**：
修改 `server.js`：
`const port = 3001;` -> `const port = process.env.PORT || 3001;`

这其实非常简单，就是让代码“听云平台的话”。
