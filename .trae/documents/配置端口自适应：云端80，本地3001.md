# 无需云端环境变量的兼容方案

收到，我们不在云端添加任何新的环境变量。

**最终方案**：
1.  **修改 `server.js`**：代码中**写死默认监听 80**。
    ```javascript
    const port = process.env.PORT || 80;
    ```
    这样部署到云端时，它就会监听 80，满足健康检查，无需任何配置。

2.  **修改本地 `.env.local`**：**仅在您本地**添加 `PORT=3001`。
    因为 `.env.local` 被 `.dockerignore` 排除了，所以这个文件**不会**被上传到云端。
    *   **本地效果**：读取到 `PORT=3001` -> 监听 3001。
    *   **云端效果**：没有 `.env.local` -> 读取不到 `PORT` -> 默认监听 80。

这样既不需要您在云端控制台配变量，又能保证本地和云端各自运行在正确的端口上。
